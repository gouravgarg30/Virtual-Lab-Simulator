# Virtual-Lab-Simulator
An EdTech web app that solves the lab access problem. Physics students can't always repeat experiments outside the lab. This simulator lets them build a simple circuit, tweak resistor values, and see current/voltage update immediately. Safe, fast, and runs on any laptop. Built with simplified ideal physics models for teaching.

## ✨ Features
* **Interactive Circuit Building:** Easily drop and connect components, tweak resistor values, and see current/voltage update instantly.
* **Projectile Motion Lab:** Adjust launch angles, initial velocities, and gravity to analyze trajectory paths, maximum height, and range in real time.
* **Simple Pendulum Experiment:** Modify string length, bob mass, and initial displacement to explore period oscillations and simple harmonic motion.
* **Accessible Anywhere:** Lightweight web app that runs smoothly on any laptop without heavy software installs.
* **Safe & Idealized Models:** Great for introductory physics students learning foundational concepts.

## 🚀 Tech Stack
* **Frontend:** HTML5,CSS3 (Flexbox,Grid,Bootstrap5),Javascript
* **Core Tech :** HTML5,CSS3 (Flexbox,Grid,Bootstrap5), vanilla Javascript(DOM,events forms, ftech, localstorage),Python-Basis,Git/Git-Hub
* **Simulation Engine:** Custom JavaScript physics models based on Ohm's Law, kinematics equations, and pendulum mechanics.
